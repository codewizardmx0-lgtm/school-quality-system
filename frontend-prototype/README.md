# النموذج الأولي التفاعلي لواجهات نظام الجودة المدرسية (Frontend Prototype)

**الشرائح المغطاة:** الشرائح 1 إلى 7 (المصادقة وإدارة النظام، التقييم الذاتي والشواهد، خطط التحسين، التقارير والتحليلات وحساب النتائج، تنظيم وجرد الشواهد، إدارة المدرسة والإحصاءات والمرافق وسياق المؤشرات، وإدارة المعايير وإصداراتها وأوزانها النسبية)  
**الهدف:** مراجعة تسلسل وسير العمليات الإجرائية والمنطقية والتحقق المباشر من تكامل الـ API الخلفي لجميع الشرائح المنفذة.

---

## 1. متطلبات التشغيل السريع

التطبيق مبني بتقنية **HTML5 + Vanilla JavaScript + CSS3** خالصة دون أي تبعيات أو حزم خارجية (Zero Dependencies / No Build Step)، مما يجعله يعمل فوراً دون مشاكل في سياسات تشغيل البرامج النصية.

### خيارات التشغيل:

#### الخيار الأول: التشغيل المباشر عبر خادم PHP المدمج (موصى به)
من المجلد الرئيسي للمشروع، شغّل الأمر التالي في الطرفية:
```bash
php -S localhost:3000 -t frontend-prototype
```
ثم افتح الرابط في المتصفح:
```
http://localhost:3000
```

#### الخيار الثاني: الفتح المباشر في المتصفح
يمكنك النقر المزدوج على ملف `frontend-prototype/index.html` وفتحه في أي متصفح حديث (Chrome / Edge / Firefox).

## 2. الاتصال بالخلفية البرمجية (Backend API)

* التطبيق يتصل تلقائياً بالخلفية البرمجية المنفذة على الرابط الافتراضي:
  ```
  http://127.0.0.1:8000/api/v1
  ```
* إذا كان خادم Laravel يعمل على منفذ آخر، يمكنك تعديل العنوان مباشرة من الحقل المخصص في الشريط العلوي للتطبيق.
* لتشغيل خادم الـ API الخلفي:
  ```bash
  cd school-eval-api
  php artisan serve
  ```

## 5. أدوات التطوير التجريبية المدمجة (Dev Tools)

* **وضع التطوير (Dev Mode):** مفتاح مدمج في ترويسة الصفحة يمكن تفعيله أو تعطيله للتحكم بظهور أدوات المطور وأزرار الدخول السريع.
* **زر «⚡ تعبئة إلزامية للاختبار (Dev Only)»:** يرصد آلياً درجات الـ 109 مؤشرات ويرفع شواهد صالحة مستوفية بنقرة واحدة، لتيسير اختبار مسار إنهاء التقييم والتقارير.
* **زر «🧹 إفراغ التقييم التجريبي»:** يعيد تصفير التقييم وحذف شواهده التجريبية لإعادة الاختبار من نقطة البداية.

## 6. المزايا المعمارية وتجربة الاستخدام المضافة

1. **التوجيه التلقائي حسب الدور الوظيفي (Role-Based Redirection):**
   - مسؤول النظام (`admin`) يُوجّه مباشرة إلى لوحة إدارة النظام.
   - مدير المدرسة (`school_principal`) يُوجّه إلى مركز إدارة المدرسة.
   - مقيّم الجودة (`school_evaluator`) يُوجّه إلى استمارة التقييم الذاتي الشجرية.
   - المشرف الوزاري (`ministry_supervisor`) يُوجّه إلى مركز الإشراف والمراجعة الخارجية.
   - مدير المعايير (`ministry_standards_manager`) يُوجّه إلى مركز وثيقة المعايير.
2. **شريط التنقل الفرعي المتكيف (`#role-nav`):** يعرض للمستخدم شريط أدوات علوي يتكيف حسب دوره لعرض التبويبات والشاشات المصرح له بها فقط مع تمييز الشاشة النشطة وتسهيل التنقل.
3. **مؤشر التحميل المركزي الموحد (`#global-spinner`):** ينبثق غطاء رمادي شفاف مع حلقة دوران ديناميكية ونص توضيحي مع كل طلب شبكي ويختفي تلقائياً فور انتهاء الطلب لحماية واجهة المستخدم من النقرات المتكررة أثناء المعالجة.
4. **المعالجة الموحدة للأخطاء والاستجابات (Unified Error Handling):**
   - الرمز 401: ينهي الجلسة ويوجه لتسجيل الدخول مع رسالة واضحة.
   - الرمز 403: يعرض رسالة توضيحية لعدم توفر الصلاحية المطلوبة.
   - الرمز 404: يبرز رسالة عدم وجود السجل أو قيد العزل المؤسسي الصارم للمدارس.
   - الرمز 422: يستخرج كافة رسائل التحقق العربية من استجابة الخادم ويعرضها للمستخدم بدقة.
5. **إدارة الشواهد بـ 3 أنماط تفاعلية:** نقل الشاهد لمؤشر مفرد، الربط المتعدد لمؤشرات متعددة عبر مربعات اختيار متزامنة، وفك الربط مع الحماية من اليتم.
6. **سلسلة تبني مجالات التحسين وإنشاء الخطط الفورية:** عند تبني مجال مقترح يظهر في قائمة المجالات المتبناة مع زر «➕ إنشاء خطة تحسين فورية من هذا المجال» الذي ينقل المستخدم لشاشة الخطط ويحدد المجال تلقائياً.
