## 3. قواعد الحوكمة والضوابط الصارمة

1. **قاعدة عدم التعديل البرمجي أو التوثيقي:**
   هذه الحزمة مخصصة للتحكيم، التحليل، التنظيم، وإعداد خطة العمل التأسيسية. لا يُسمح بإجراء أي تعديل على كود الواجهة الخلفية أو الأمامية، أو قاعدة البيانات والتهجيرات، أو وثيقة التخرج، أو ملفات المراجعات الأصلية في هذه المرحلة.
2. **الالتزام بالمصطلح الرسمي المحظور:**
   يُحظر استخدام مصطلح «اعتماد» ومشتقاته في أي سياق إجرائي داخل المنصة (مثل اعتماد التقييم، اعتماد الخطة، اعتماد الشاهد)، ويقتصر استخدامه حصراً على التسمية التشريعية الرسمية: «معايير الاعتماد المدرسي». وتُستبدل الإجراءات البرمجية والتوثيقية بالمصطلحات المنضبطة: «إقرار / تدقيق / تسليم / مراجعة / اكتمال / إتمام».
3. **مبدأ «التنظيم بلا فقد»:**
   كافة المشكلات الـ 42، والجزئيات الـ 268، والملاحظات الأصلية الـ 229، والأسئلة الـ 18، محفوظة بالكامل بأدلتها وإحالاتها دون اختزال أو إسقاط.
