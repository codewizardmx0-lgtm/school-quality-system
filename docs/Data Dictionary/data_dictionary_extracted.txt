[HEADING/TEXT] هذا القاموس هو الترجمة الحرفية لمخطط ERD-0 المفصل النهائي إلى مواصفة تنفيذية: منه تُكتب Migrations مباشرة، ومنه تُبنى حقول الـAPI وأنواع TypeScript ونماذج الواجهات. أسماء الجداول في ERD بحروف كبيرة والتنفيذ المتفق عليه بأحرف صغيرة (اتفاقية MySQL).
[HEADING/TEXT] • أضفت عمود Length بقيم مقترحة لأن ERD لا يحدد الأطوال — عدّلها بحرية بما لا يخالف الأنواع.
[HEADING/TEXT] • أضفت أسفل الجداول ذات القيود المركبة سطر «قيود الجدول» — لأن أعمدة الجدول الثمانية تعرض قيود العمود المفرد فقط، والقيد المركب صفّي.
[HEADING/TEXT] • قيمة «شرطي» في عمود Required تعني: العمود اختياري في قاعدة البيانات لكن إلزامي بموجب شرط (مثل قاعدة الجهة الواحدة أو قيد CHECK لمصدر واحد على الأقل).
[HEADING/TEXT] • اتفاقية التسمية الموحدة: قيم حالات الكيانات (Enums) بصيغة PascalCase — مطابقة للحالات الخمس المنصوصة في 3.10.8 — بينما قيم الأنواع والمعرفات المركبة (target_type، أنواع الإشعارات، input_scope) بصيغة snake_case. ثبّتها كـEnum واحد في الكود (PHP Enum + ثوابت TypeScript) ولا تبعثرها نصوصًا.

[HEADING/TEXT] ERD-02: الإطار المرجعي والإصدارات وأدوات التحقق
[HEADING/TEXT] يغطي المرجعية الرسمية للمعايير: الإصدارات المعيارية الموثقة المصدر وهيكلها الهرمي (إصدار ← معيار رئيس ← معيار فرعي ← مؤشر)، وسلم الدرجات (0–3)، والأوصاف الرسمية لتقدير كل مؤشر، ومتطلبات الشواهد وأدوات وأساليب التحقق. القراران الحاكمان: المؤشر هو وحدة التقييم الذرية، ولا يُعدَّل محتوى الإصدار بعد اعتماده.

[HEADING/TEXT] 2) المراجع متعددة الأشكال (Polymorphic)
[HEADING/TEXT] جدولان يعتمدان نمط (نوع + معرف) بدل مفاتيح أجنبية مباشرة: attachments (هدفه: نسخة شاهد أو تقرير) وnotifications (مصدره: طلب استكمال أو دورة أو إصدار أو إجراء). لا يستطيع MySQL فرض هذه المرجعية كمفتاح أجنبي — تُفرض في طبقة التطبيق، مع فهرس مركب إلزامي على العمودين معًا في كل جدول.
