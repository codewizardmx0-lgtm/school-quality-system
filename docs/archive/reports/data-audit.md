## 2. نتائج الفحص النوعي والحالات الشاذة

### 2.1 المؤشرات التي ليس لها 4 واصفات أداء بالضبط
- **العدد:** 0 مؤشر.
- **النتيجة:** كل مؤشر من المؤشرات الـ 109 يمتلك بالضبط 4 واصفات معيارية تغطي المستويات (0، 1، 2، 3).

### 2.2 الواصفات الفارغة (Empty Descriptors)
- **العدد:** 0 واصفة.
- **النتيجة:** لا توجد أي واصفة بحقل نصي فارغ أو معدوم (`NULL` أو نص أبيض)؛ جميع الواصفات الـ 436 محشوة بنصوص معيارية رسمية مستخرجة من الوثيقة.

### 2.3 الواصفات المكررة نصاً لنفس المؤشر بين مستويين
- **العدد:** 0 تكرار.
- **النتيجة:** نصوص الواصفات لكل مؤشر متدرجة ومتمايزة بوضوح بين المستويات (0، 1، 2، 3) دون أي تطابق لفظي لنفس المؤشر.

### 2.4 المؤشرات غير المرتبطة بأدوات تحقق (Verification Tools)
- **العدد:** 0 مؤشر.
- **النتيجة:** جميع المؤشرات الـ 109 مغذاة بروابط أدوات التحقق المعتمدة في جدول `indicator_verification_methods`.

### 2.5 المؤشرات غير المرتبطة بمتطلبات شواهد (Evidence Requirements)
- **العدد:** 0 مؤشر.
- **النتيجة:** جميع المؤشرات الـ 109 لها متطلبات شواهد رسمية مسجلة في جدول `indicator_evidence_requirements`.

### 2.6 فحص تطابق تسميات المستويات في `score_levels` مع `ScoreLevelSeeder`
- **المستوى 0 (score_value = 0):** `غير متوفر` — **مطابق**.
- **المستوى 1 (score_value = 1):** `متحقق بدرجة ضعيفة` — **مطابق**.
- **المستوى 2 (score_value = 2):** `متحقق بدرجة متوسطة` — **مطابق**.
- **المستوى 3 (score_value = 3):** `متحقق` — **مطابق**.
