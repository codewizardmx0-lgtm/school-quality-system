# قالب الخطة التشغيلية للأنشطة المدرسية واللاصفية

## أولاً: بطاقة تعريف الشاهد
* **المعيار الرئيسي:** STD-05 (البيئة المدرسية) / STD-06 (الشراكة)
* **المعيار الفرعي:** SUB-5-2 (المرافق والأنشطة التعليمية)
* **رمز المؤشر المرتبط:** 5-2-3 و 6-1-3
* **أداة التحقق:** فحص السجلات وملاحظة الفعاليات
* **مستوى الأداء المستهدف:** المستوى (3) - متحقق
