# سجل فجوات ونواقص الواجهة الأمامية (Frontend Gaps Register)
## متابعة وتطوير واجهات React (`school-eval-web`)

> **المشروع:** نظام إدارة الجودة والتقويم والاعتماد المدرسي (`school-quality-system`)  
> **حالة الوثيقة:** وثيقة تشغيلية حية لحصر وتتبع كافة متطلبات ونواقص الواجهات الأمامية المتبقية.  
> **تاريخ التحديث:** 7 نوفمبر 2026م.  
> **الفرع الحالي:** `feature/school-evaluator-ui`.  
> **خطة المعالجة المعتمدة:** يُحال للتفاصيل التنفيذية وجدول الأولويات إلى [docs/gap-remediation-plan.md](gap-remediation-plan.md).  

---

## 1. ملخص حالة الواجهات الأمامية

* **واجهات مقيم المدرسة (`school_evaluator`):** **مكتملة 100%** وجاهزة تشغيلياً (لوحة التحكم، شجرة المعايير، استمارة الرصد الرباعية، مستودع الشواهد، جرد الـ 109 مؤشرات، الربط المتعدد، تحليل الفجوات، خطة التحسين، الختم الرقمي، ومعالجة طلب الاستكمال).
* **واجهات مدير المدرسة (`school_principal`):** **مكتملة 100%** (وضع القراءة والمراجعة المقفل، شريط التنبيه، وصندوق اعتماد المراجعة الداخلية).
* **واجهات مسؤول النظام (`admin`):** **مكتملة 92%** (إدارة المدارس، إدارة المستخدمين، وسجل التدقيق الأمني، وإعدادات النسخ الاحتياطي).
* **واجهات المشرف الوزاري (`ministry_supervisor`):** **0% في React** (متوفرة بالكامل في الباك إند ونموذج `frontend-prototype`).
* **واجهات مسؤول المعايير (`ministry_standards_manager`):** **25% في React** (شجرة المعايير متوفرة؛ إدارة الإصدارات والاعتماد متوفرة في الباك إند والـ Prototype فقط).

## 2. جدول الفجوات المفتوحة للواجهة الأمامية (Open Frontend Gaps)

| كود الفجوة | عنوان الفجوة | الوصف الفني والتفصيلي | الأولوية | الملفات المتأثرة / المستهدفة | الحل الفني والمسار التنفيذي المقترح |
|:---:|---|---|:---:|---|---|
| **FE-GAP-01** | بناء حزمة شاشات المشرف الوزاري (`features/supervision`) | عدم وجود شاشات React لدور المشرف الوزاري؛ وتقتصر حالياً على الـ Prototype والباك إند. تشمل: لوحة متابعة المدارس، إدارة دورات التقييم، فحص الشواهد والنتائج المرفوعة، إصدار طلب استكمال، والاعتماد النهائي. | **عالية** | مجلد جديد: `src/features/supervision/` | بناء المكونات التفاعلية وربطها بالمسارات الجاهزة في الباك إند (`/api/v1/supervision/*` و `/api/v1/evaluation-cycles/*`). |
| **FE-GAP-02** | بناء شاشات إدارة المعايير الوطنية (`features/standards`) | غياب واجهات React لمسؤول المعايير لإدارة مسودات الإصدارات وتعديل الواصفات وحساب مجموع الأوزان (100%) وتفعيل الإصدار المعياري. | **متوسطة** | مجلد جديد: `src/features/standards/` | بناء شاشات تفعيل الإصدارات واستنساخ المعايير وربطها بـ `StandardVersionController`. |
| **FE-GAP-03** | واجهات استعادة كلمة المرور المنسية (`PasswordResetPage`) | مسارات الباك إند مكتملة 100% ومختبرة، وتعمل في الـ Prototype، وتم بناء شاشات ومودال React كاملة وربطها بالمسار. | **محلولة ✅** | `src/features/auth/ForgotPasswordModal.tsx` و `ResetPasswordPage.tsx` | تم بناء النموذج التفاعلي وشاشة الاستعادة المستقلة وربطهما بـ `/api/v1/auth/password/*`. |
| **FE-GAP-04** | الرسوم البيانية التفاعلية المتقدمة (Interactive Charts) | تم بناء مكونين تفاعليين خفيفين بنظام SVG (`InteractiveDonutChart` و `InteractiveBarChart`) ودمجهما في لوحة تحكم المقيم لدعم التكبير وتوزيع المستويات. | **محلولة ✅** | `src/components/ui/` و `EvaluatorDashboard.tsx` | تم تطوير المكونات التفاعلية وعرضها في لوحة تحكم المقيم لمقارنة المعايير السبعة وتوزيع مستويات 0-3. |
| **FE-GAP-05** (`U-35`) | دعم وضع العمل بدون اتصال بالإنترنت (Offline Caching) | تم دعم التخزين المحلي للمسودات عند انقطاع الشبكة مع شريط تنبيه برتقالي ومزامنة تلقائية عند الاتصال ومعالجة تعارض بسيطة. | **محلولة ✅** | `src/features/evaluation/hooks/useSelfEvaluation.ts` و `RubricAssessmentPage.tsx` | تم حفظ المسودات محلياً مع طابع زمني، وفحص التعارض مع الخادم والمزامنة التلقائية فور عودة الاتصال. |
| **FE-GAP-06** | دعم السحب والإفلات للشواهد (Drag & Drop) | تم بناء منطقة إسقاط تفاعلية ذكية تفحص الحجم والامتداد فورياً وتدعم السحب والإفلات أو التصفح التقليدي. | **محلولة ✅** | `src/features/evaluation/components/evidences/UploadEvidenceModal.tsx` | تم تطوير المكون ليدعم السحب والإفلات والفحص الفوري للحجم والصيغ وإلغاء التحديد. |
| **FE-GAP-07** (`U-42`) | واجهة المحادثة التفاعلية للمساعد الذكي الحي (Gemini Chat UI) | واجهة المساعد الذكي الحالية تستعرض مصفوفة التوصيات الثابتة ومقترحات المعادلات؛ وتنتظر الشريحة 12 لبناء نافذة تفاعلية حية مع نموذج الذكاء الاصطناعي. | **متوسطة** (الشريحة 12) | `src/features/evaluation/components/ai-assistant/` | بناء مكون محادثة ذكي ومحكوم يدعم استعراض التوصيات وتطبيقها مباشرة بضوابط الحوكمة (`BR-AI-01..02`). |

## 3. الفجوات المغلقة مؤخراً في واجهات المقيم (Closed Frontend Gaps)

1. ✅ **تصدير تقرير التقييم PDF حقيقي:** تم ربط استدعاء الـ API الثنائي مع محرك mPDF وحل مشكلة تنزيل ملف نصي بديل.
2. ✅ **الربط المتعدد للشواهد (Multi-Link):** تم بناء نافذة `LinkEvidenceModal.tsx` وربطها بالكامل مع الـ Backend.
3. ✅ **شاشة جرد وحصر الشواهد (109 مؤشرات):** تم إنشاء `EvidenceInventoryPage.tsx` لحصر النواقص والمستوفى.
4. ✅ **وضع القراءة الصارم لمدير المدرسة:** تم قفل كافة أزرار الرصد والرفع والختم وإظهار شريط التنبيه الإرشادي.
5. ✅ **نافذة الملف الشخصي الشاملة (`ProfileModal.tsx`):** تم بناء 3 تبويبات للمعلومات والأمان والمظهر مع حماية اسم المستخدم.
6. ✅ **واجهات استعادة وإعادة تعيين كلمة المرور (`FE-GAP-03`):** تم بناء `ForgotPasswordModal.tsx` و `ResetPasswordPage.tsx` وربطهما بمسارات الباك إند مع التحقق والتحويل التلقائي.
7. ✅ **السحب والإفلات في رفع الشواهد (`FE-GAP-06`):** تم تحديث `UploadEvidenceModal.tsx` لإتاحة السحب والإفلات التفاعلي مع فحص فوري للصيغ والحجم.
8. ✅ **الرسوم البيانية التفاعلية للمقيم (`FE-GAP-04`):** تم بناء مكونات SVG التفاعلية `InteractiveDonutChart` و `InteractiveBarChart` ودمجهما في لوحة تحكم المقيم لعرض مستويات الأداء والمجالات السبعة بدقة وتوافق تام مع التكبير (125% و 150%).
9. ✅ **وضع عدم الاتصال بالإنترنت ومعالجة التعارض (`FE-GAP-05` / `U-35`):** تم دعم التخزين المحلي الآمن لمسودة الرصد، وإظهار شريط تنبيه الحفظ المحلي، والمزامنة التلقائية عند عودة الشبكة مع معالجة التعارض (Conflict Resolution).
